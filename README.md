## Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### Installation

Clone the repository and install dependencies:

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Then open the local URL printed in your terminal, typically:

```text
http://localhost:port




### Hero Portrait

The current hero uses a generated abstract SVG through:

```text
TerminalPortrait
```

inside:

```text
src/components/HeroSection.tsx
```

It can be replaced with a personal photograph, custom illustration, or another visual identity asset.

## Design & Interaction

The portfolio is intentionally built around a **dark, technical, editorial aesthetic** rather than a conventional developer portfolio.

Key interaction patterns include:

- Magnetic hover interactions
- Scroll-linked animations
- Character-by-character text reveals
- Horizontal technology marquees
- Sticky project cards
- Layered transitions
- Responsive layouts
- Reduced-motion support

The goal is to make the interface feel **engineered, interactive, and intentional** while keeping the content readable.

## Accessibility

The portfolio respects:

```css
prefers-reduced-motion
```

so users who prefer reduced animation receive a less motion-intensive experience.
